Brief de marketing interactivo de NFOKU para Omar, fisioterapeuta (GDL). Estado: **lead** (aún no es cliente).

| Archivo | Qué es |
|---|---|
| `index.html` | Brief interactivo. Omar responde y lo envía por WhatsApp a NFOKU (33 1672 2781). |
| `og.png` | Miniatura 1200×630 para la vista previa del enlace en WhatsApp. |

**Enlace para compartir:** https://nfokumkt-gdl.github.io/leads/omar-fisioterapeuta/

## Cómo llegan las respuestas
1. Omar toca **Enviar por WhatsApp** → se abre un chat con NFOKU con un resumen y un enlace largo `…/#r=…`.
2. Ese enlace abre sus respuestas completas en modo reporte (web). Botón **Descargar PDF** para guardarlo.
3. Las respuestas viajan dentro del enlace (comprimidas); no se guardan en ningún servidor.

## Notas
- Si cambia la ruta o el repo, actualiza la URL en las etiquetas `og:` de `index.html` (WhatsApp necesita la URL absoluta de `og.png`).
- Para cambiar el número de WhatsApp busca `523316722781` en `index.html`.
- Cuando defina nombre e identidad, se crea su carpeta en el repo `clientes`.
